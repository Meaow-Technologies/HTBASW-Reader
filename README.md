## 📖 About How to Become a Star Writer

**How to Become a Star Writer** is a work by SingNShong. This reader provides a
clean, browser-based reading experience for the available chapters, with
progress tracking, bookmarks, customizable reading settings, chapter
discussions, and EPUB downloads.

The project currently publishes one edition:

- **Story** — The available story chapters, including the author notice.

---

## ✨ Features

- **Static Reader** — Fast chapter pages generated from validated XHTML
  sources.
- **Custom Themes** — Fourteen built-in themes: Forest Night, Warm Paper,
  Daylight, Nord, Dracula, Solarized Dark, Catppuccin Mocha, OLED Black, plus
  Material You Lavender Light, Lavender Dark, Sage Light, Sage Dark, Blue
  Light, and Blue Dark palettes.
- **Reader Settings** — Adjustable font family, text size, themes, and a full
  background customizer with image, URL, solid colour, blur, brightness, zoom,
  and positioning controls.
- **EPUB Download** — Download the complete available story as a generated
  EPUB 3 file.
- **Bookmarks & Progress** — Stored locally in the browser with no account or
  synchronization required.
- **Chapter Comments** — Per-chapter discussions powered by
  [Giscus](https://giscus.app) and GitHub Discussions.
- **Discord Notifications** — Optional GitHub Discussion comment forwarding
  through a Cloudflare Pages webhook.
- **Privacy First** — No trackers, no ads. Reading settings and progress stay
  in the visitor's browser.
